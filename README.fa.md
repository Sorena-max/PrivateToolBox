# PrivateToolBox

سخت سازی و بهینه سازی امن یک سرور لینوکسی، در یک ابزار. سرورت را میبیند، دقیق نشان میدهد چه چیزی
را عوض میکند، اعمال میکند و اگر مشکلی پیش بیاید همه چیز را خودش برمیگرداند.

[English](README.md) | [راهنمای سریع](GUIDE.fa.md) | [Quick guide](GUIDE.md)

- 🔍 **اسکن** به سرورت امتیاز 0 تا 100 میدهد و چیزی را عوض نمیکند
- 🧾 **اول نقشه**: هر تغییر قبل از انجام شدن فهرست میشود و بدون تایید تو چیزی اعمال نمیشود
- ⏪ **برگشت هر چیز**: هر اجرا ثبت میشود و `privatetoolbox undo` همه فایل ها و تنظیم ها را برمیگرداند
- 🛟 **برگشت خودکار** که به ترمینال تو وابسته نیست: تغییر های پرخطر یک تایمر systemd میسازند و اگر به موقع
  تایید نکنی (حتی اگر SSH قطع شده باشد) سرور به حالت قبل برمیگردد
- 🌐 فارسی و انگلیسی
- 🇮🇷 چک اختیاری اینکه بعد از تغییر هنوز از ایران به سرور میرسند، و گزارش اختیاری به ربات
  [PrivateChecker](https://github.com/Sorena-max/PrivateChecker)

## نصب

یک سرور لینوکسی با systemd و دسترسی root لازم است. روی Ubuntu 22.04 به بالا و Debian 12 به بالا تست شده.

```bash
curl -fsSL https://raw.githubusercontent.com/Sorena-max/PrivateToolBox/main/install.sh | sudo bash
```

این فقط فایل ها را در `/opt/privatetoolbox` میگذارد و دستور `privatetoolbox` را اضافه میکند. تنظیمات سرور را
عوض نمیکند. برای نصب یک نسخه مشخص بعد از `bash -s --` گزینه `--ref v0.1.0` را اضافه کن.

## استفاده

```bash
sudo privatetoolbox                         # منوی تعاملی
sudo privatetoolbox scan                    # امتیاز و یافته ها، فقط خواندن
sudo privatetoolbox plan --profile vpn      # نشان بده چه چیزی عوض میشود
sudo privatetoolbox apply --profile vpn     # اعمال (اول میپرسد و تایمر برگشت را میسازد)
sudo privatetoolbox apply bbr dns           # یا ماژول ها را با اسم انتخاب کن
sudo privatetoolbox undo                    # آخرین اجرا را برگردان
sudo privatetoolbox verify --iran           # بررسی کن همه چیز کار میکند و ایران به سرور میرسد
```

وقتی SSH یا فایروال عوض میشود، `apply` این کارها را میکند:

1. نقشه را نشان میدهد و میپرسد
2. تایمر برگشت را میسازد (پیش فرض 120 ثانیه)
3. اعمال میکند و بعد چک میکند همه چیز کار میکند
4. از تو میخواهد یک ترمینال جدید باز کنی، مطمئن شوی هنوز میتوانی وارد شوی و `yes` بنویسی
5. اگر ننویسی تایمر کل اجرا را برمیگرداند

با `--yes` (برای اسکریپت ها) فقط وقتی همه بررسی ها درست باشد تغییرها نگه داشته میشوند، وگرنه تایمر برمیگرداند.

## ماژول ها

| ماژول | کارش |
|---|---|
| `dns` | Cloudflare و Google و Quad9 و OpenDNS و AdGuard را از سرور تو میسنجد و بهترین را میگذارد |
| `bbr` | اگر کرنل پشتیبانی کند BBR را با صف fq روشن میکند |
| `sysctl` | سخت سازی و بهینه سازی امن شبکه کرنل (SYN cookies، redirect ها، rp_filter ملایم، backlog و ...) |
| `ssh` | سخت سازی با فایل drop-in (تعداد تلاش ورود، ورود root، X11)، ورود فقط با کلید و پورت اضافه اختیاری |
| `firewall` | UFW: اول SSH را باز میکند، بعد پورت هایی که از قبل شنود میکنند، و پورت های خودت |
| `fail2ban` | حدس زدن رمز SSH را بن میکند و هرگز تو را بن نمیکند |
| `abuse` | اتصال های تازه خروجی به رنج های خصوصی و رزرو شده را میبندد تا دیتاسنتر دیگر گزارش آبیوز نفرستد |
| `ipv6` | IPv6 را خاموش میکند (اگر با IPv6 وصل باشی رد میکند) |
| `mss` | محدودیت TCP MSS برای سرورهایی که ترافیک عبوری دارند |
| `updates` | آپدیت امنیتی خودکار |
| `timesync` | مطمئن میشود ساعت همگام است |
| `journald` | حجم لاگ سیستم را محدود میکند |
| `swap` | روی سرورهای کوچک فایل swap میسازد |

پروفایل ها: `recommended` و `vpn` و `web` و `bot` و `game` و `all`. محتوای هر کدام را با
`privatetoolbox plan --profile vpn` ببین.

### گزینه ها

```text
--dns auto|keep|cloudflare|google|quad9|opendns|adguard
--ssh-port N              روی این پورت SSH هم گوش بده (پورت قبلی میماند)
--ssh-keys-only           ورود با رمز را خاموش کن (کلید تو لازم است)
--open "443 51820/udp"    پورت های اضافه برای باز کردن
--exclude "8080"          پورت های در حال شنود که بسته بمانند
--no-discover             فقط SSH و پورت هایی که اسم میبری
--forward-accept          UFW ترافیک عبوری را بگذراند (NAT و VPN)
--abuse-profile minimal|aggressive    و  --block-smtp
--rollback SECONDS | --no-rollback    --notify    --iran
```

## ایمنی

- فایروال پیش از روشن شدن پورت SSH تو (و پورتی که با آن وصل هستی) را باز میکند.
- پورت جدید SSH کنار قبلی اضافه میشود و قبلی برداشته نمیشود.
- محافظ آبیوز هرگز جواب اتصال های ورودی را نمیبندد و زیرشبکه خودت، گیت وی، DNS ها و آدرس metadata ابری را دست نمیزند.
- ورود با رمز فقط وقتی خاموش میشود که حساب خودت کلید داشته باشد و `sshd -t` درست باشد.
- فایل های تنظیماتی که عوض میشوند اول ذخیره میشوند. اگر مرحله ای خطا بدهد هرچه تا آن لحظه شده برمیگردد.
- ثبت هر اجرا در `/var/lib/privatetoolbox` است (فقط root میخواند).

## حذف

```bash
sudo privatetoolbox undo          # آنچه عوض شده را برگردان
sudo privatetoolbox uninstall     # برنامه را حذف کن (با --purge تاریخچه هم پاک میشود)
```
